Pixel placer

One pixel at a time, in string order. Panel face down, flipped sideways like a book page: the map's top is still at the top, and the sign is at the bottom left.

Before you start each output

  1. Count along the string and put a bit of tape on pixel 0, 10, 20, 30 and 40, writing the number on it. Do the same on the second string: 50, 60, 70 and so on. Miscounting by one is what shifted the last attempt.
  2. Pixel 0 is the one nearest the plug that goes into the Sparkle Motion.
  3. The number on the tile plate beside each hole should match the big number here. Use it as a check, not as the guide.
  4. At a SKIP, leave that pixel out of the map and push it into a printed cup. The next number goes in the next hole.
